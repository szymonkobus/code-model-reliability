Metric names

A static copy; data as of 22 September 2026.

Reserved words: bare reliability = the average-rate 1% crossing only; bare capability = the average-rate 50% crossing only.

A. Curve crossings

name what it is
average-rate 1% crossing where the model's fitted average failure rate first reaches 1%
median-task 1% crossing where the median task's failure rate reaches 1%
average-rate 50% crossing where the fitted average failure rate reaches even odds
median-task 50% crossing where the median task reaches even odds
level pair (1%, 50%) two linked crossings, always written with concrete levels: (1%, 50%), (2%, 40%), … never variables

B. Cumulative failure rates

name what it is
cumulative 1% failure rate the hardest difficulty such that average failure over ALL easier tasks is still ≤ 1%
worst-stretch 1% failure rate the same, but EVERY trailing stretch of easier tasks must stay ≤ 1%; easy wins cannot bank budget for later failures
first task above 1% failure the last difficulty before the first single task failing more than 1%
cumulative X% failure rate the same machine at any other concrete anchor
99%-assured (prefix) any of the above, quoted at the value it holds with 99% posterior probability

C. Axis totals

name what it is
success-mass balance point everything the model solves, added up and read as one position on the difficulty axis: mean pass rate expressed as a difficulty
contested mass how much of the difficulty axis the model SOMETIMES solves and sometimes fails: the width of its struggle zone
easy-success subsidy cumulative minus worst-stretch: how much quoted range was earned by easy wins rather than held everywhere
