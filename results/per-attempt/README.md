# Per-attempt verdicts, wave 1

One row per attempt of every published full arm on wave 1: the arm, the task, the attempt index, and the verdict on the base tests and on the extended tests as recorded by the pinned judge. Rows are as judged; no program text is included. An arm appears for a benchmark only if it has a published full run on it (one arm ran the first benchmark only); export-report.json beside this file records the arms written per benchmark.
